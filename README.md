# Nuno Miguel Rodrigues dos Santos

AI governance researcher at **CEPCEP – Universidade Católica Portuguesa** and Coordinator of Technical & Administrative Support at Portugal's **Ministry of Finance**.

I build Python tools that automate work in public administration and in my own research, and I study how AI reshapes propaganda, disinformation and institutional power, especially in Portuguese-speaking contexts.

## What I work on

- **Automation for public administration.** Python tools that replace manual workflows; at the Ministry of Finance they save 200+ hours of manual processing each month.
- **AI governance research.** Computational propaganda, algorithmic accountability and AI-mediated disinformation. I developed the *TAI Model* (Technology–Audience–Institution tension).
- **Applied AI.** LLM API integration, AI agents and data analytics.
